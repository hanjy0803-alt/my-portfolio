# 포트폴리오

GitHub Pages용 정적 사이트입니다. 저장소 루트의 `index.html`이 첫 화면이며, `chatbot.html`은 포트폴리오에서 연결됩니다.

공개 파일: `index.html`, `chatbot.html`, `styles.css`, `app.js`, `guestbook-config.js`, `guestbook.js`, `assets/`의 이미지·SVG, `data/financials.json`.

방명록은 방문자가 로그인 없이 글을 남길 수 있도록 준비했지만, 공유 저장소가 아직 연결되지 않아 화면에서 숨겨져 있습니다. Supabase 프로젝트가 준비되면 로컬의 `GUESTBOOK_SETUP.md`에 따라 테이블과 공개용 키를 설정합니다. 비밀키는 사이트에 넣지 않습니다.

OpenDART 인증키가 들어 있는 `.env`와 원본 공시 다운로드 파일은 공개하지 않습니다. 재무정보의 근거는 [2025년 사업보고서](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260320000859)입니다.
