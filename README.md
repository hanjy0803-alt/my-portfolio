# 포트폴리오

GitHub Pages용 정적 사이트입니다. 저장소 루트의 `index.html`이 첫 화면이며, `chatbot.html`은 포트폴리오에서 연결됩니다.

공개 파일: `index.html`, `chatbot.html`, `styles.css`, `app.js`, `assets/profile.jpg`, `assets/hd-hhi-logo.png`, `data/financials.json`.

OpenDART 인증키가 들어 있는 `.env`와 원본 공시 다운로드 파일은 공개하지 않습니다. 재무정보의 근거는 [2025년 사업보고서](https://dart.fss.or.kr/dsaf001/main.do?rcpNo=20260320000859)입니다.
